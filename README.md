# NoteNest

A simple personal notes manager that keeps your notes organised and saved in your browser.

**Live app:** https://razorjetinz.github.io/notenest/ (after enabling GitHub Pages)

## Features

- Create, edit and delete notes.
- Automatic saving to browser Local Storage.
- Organise notes with categories and comma-separated tags.
- Pin important notes.
- Search across note titles, content, categories and tags.
- Export an individual note or all notes as Markdown.
- Responsive layout and light/dark colour themes.
- No account, server, database, external library or build step.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Start writing. Notes are saved automatically in that browser on that device.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**.
4. Save. GitHub Pages will publish the app at the URL shown in the Pages settings.

## Privacy and storage

NoteNest stores notes in the browser's Local Storage. Note content is not uploaded to a server. This means notes are local to the browser and device: they are not automatically synchronised across devices, and clearing browser site data can delete them. Export important notes regularly using **Export all**.

## Keyboard shortcut

- `Ctrl+N` (or `Cmd+N` on macOS): create a new note.
